### Que aprendí
- WSL2 usa un kernet de Linux real, provisto por Microsoft. Ubuntu aporta las herramientas, no el kernel.
- 'ls-la' muestra el tipo de archivo, los permisos, el dueño y el tamaño.
- Una llave SSH es un par: la privada firma y la pública verificada. La privada nunca se comparte.
